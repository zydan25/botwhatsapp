API V4

هذه اللوحة تعمل على نفس طبقة V4 التي يستخدمها تطبيق العميل.

توكنات Bearer الحالية تبقى كما هي. لا يوجد تدوير مفاتيح عند استخدام لوحة الإدارة.

نقاط عامة

GET /takhfid/api/v4/health
GET /takhfid/api/v4/store
GET /takhfid/api/v4/content
GET /takhfid/api/v4/categories
GET /takhfid/api/v4/pricing
GET /takhfid/api/v4/products
GET /takhfid/api/v4/products/<id>

الطلبات

POST /takhfid/api/v4/orders
GET  /takhfid/api/v4/orders
GET  /takhfid/api/v4/orders/<id>
PATCH /takhfid/api/v4/orders/<id>/status
PATCH /takhfid/api/v4/orders/<id>/payment
