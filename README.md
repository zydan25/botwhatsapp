# WhatsApp Pro Multi Session

نظام متعدد الجلسات لإدارة WhatsApp Web عبر `whatsapp-web.js` مع لوحة تحكم عربية.

## التشغيل الآمن

انسخ `.env.example` إلى `.env` واضبط المتغيرات المطلوبة:

```bash
cp .env.example .env
npm install
npm start
```

المتغيرات الإلزامية هي `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SESSION_SECRET`.

ثم افتح:

- لوحة التحكم: `http://127.0.0.1:3000`
- صفحة الجلسة: `http://127.0.0.1:3000/<sessionName>`

## إدارة الجلسات

من لوحة التحكم يمكن إنشاء جلسة، تشغيلها، إيقافها، تسجيل الخروج، أو حذفها نهائيًا.

حذف الجلسة يحذف بيانات اعتماد WhatsApp المحلية وسجل الرسائل والأخطاء والتنبيهات الخاصة بها.

## الأمان

جميع صفحات الإدارة وواجهات `/api/*` محمية بتسجيل دخول عبر cookie آمن (`HttpOnly` و`SameSite=Strict`). اتصال Socket.IO يتطلب جلسة دخول صالحة.

رفع الوسائط محدود بالحجم والعدد، ويتم حذف ملف الوسائط المؤقت بعد محاولة الإرسال.

لا يتم تعريض الخادم خارجيًا افتراضيًا؛ `HOST` هو `127.0.0.1` ما لم يتم تغييره عمدًا خلف reverse proxy موثوق.

## ملاحظات

- الجلسات تستخدم `LocalAuth` باسم مستقل.
- الرسائل الواردة لا يتم تنزيل مرفقاتها تلقائيًا.
- كل جلسة يمكن ربطها بـ API خارجي مستقل.
- يجب استخدام HTTPS لأي API خارجي؛ HTTP مسموح فقط لـlocalhost/loopback للتطوير المحلي.
- هذه المكتبة تعتمد على WhatsApp Web وليست عميلًا رسميًا من WhatsApp، لذلك التوافق المستقبلي ليس مضمونًا.
