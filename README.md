# WhatsApp Pro Multi Session

منصة متعددة الجلسات لـ WhatsApp Web مع بوابة إدارة للمشرف وبوابة عميل مرتبطة بجلسة واحدة لكل حساب.

## النطاقات

المشرف:

`https://admin.whatsapp.alattab.site`

العميل + API:

`https://whatsapp.alattab.site`

الخادم نفسه يمكن أن يعمل خلف Nginx/Cloudflare، بينما يستمع Node محليًا على `127.0.0.1:3000` افتراضيًا.

## التشغيل

```bash
cp .env.example .env
npm install
npm start
```

ضع في `.env`:

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `SESSION_SECRET` بقيمة عشوائية طويلة
- `ADMIN_HOST=admin.whatsapp.alattab.site`
- `CLIENT_HOST=whatsapp.alattab.site`

## إنشاء عميل

من لوحة المشرف أنشئ جلسة جديدة وحدد اسم الجلسة والوصف ورابط API واسم مستخدم العميل وكلمة المرور. الحساب يُربط تلقائيًا بهذه الجلسة، ولا يستطيع العميل الوصول إلى جلسة أخرى.

## API / Webhook

إذا كان عنوان API هو:

`http://api.example.com`

سيتم إرسال الرسائل إلى:

`http://api.example.com/webhook/whatsapp`

وسيتم إرسال تغيّر الحالة إلى:

`http://api.example.com/webhook/session-status`

وسيتم إرسال حدث QR إلى:

`http://api.example.com/webhook/qr`

يدعم النظام HTTP وHTTPS للـAPI الخارجي. كل طلب Webhook يحمل:

`x-whatsapp-signature: sha256=<HMAC-SHA256>`

يتم حساب التوقيع على كامل JSON body باستخدام Webhook Secret الخاص بالجلسة.

## الخصوصية والملفات

لا يتم تنزيل أو حفظ مرفقات WhatsApp الواردة. وعند إرسال مرفق من لوحة التحكم، يُقرأ في الذاكرة فقط باستخدام Multer memory storage ثم يُمرر مباشرة إلى WhatsApp؛ لا يتم إنشاء ملف upload دائم على القرص.

## إعادة المصادقة

`إعادة التشغيل` تعيد تشغيل العميل مع الاحتفاظ ببيانات اعتماد WhatsApp.

`إعادة توليد QR` تعيد تشغيل اتصال ينتظر QR.

`إعادة المصادقة` تحذف بيانات اعتماد WhatsApp المحلية للجلسة فقط ثم تبدأ اتصالًا جديدًا مع الاحتفاظ بحساب العميل ورابط API والوصف وWebhook Secret.

## حذف جلسة

حذف الجلسة من لوحة المشرف يوقف اتصال WhatsApp ويحذف بيانات اعتماد WhatsApp المحلية وسجل الرسائل والأخطاء والتنبيهات، ويحذف حساب العميل المرتبط بها.

## PWA

بوابة العميل قابلة للتثبيت كتطبيق PWA على الهاتف والكمبيوتر، مع تصميم متجاوب. زر `تثبيت كتطبيق` يظهر عندما يسمح المتصفح بحدث التثبيت.

## بيانات العميل

بوابة العميل تعرض الحالة الحالية ورقم الحساب وQR ووصف الجلسة ورابط API ومسارات Webhook وWebhook Secret ونموذج JSON وتعليمات المصادقة وسجل الرسائل والأحداث وتغيير كلمة المرور.
