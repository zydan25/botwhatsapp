# WhatsApp Pro Multi Session

نظام احترافي متعدد الجلسات لكل جلسة:
- اسم مستقل
- مسار مستقل `/sessionName`
- API مستقل
- QR مباشر
- سايدبار للجلسات
- تحديث لحظي عبر Socket.IO
- حفظ محلي JSON بدون قاعدة بيانات خارجية

## التشغيل
```bash
npm install
npm start
```

ثم افتح:
- لوحة التحكم: `http://127.0.0.1:3000`
- الجلسة: `http://127.0.0.1:3000/alattab1`

## ملاحظات
- الجلسات تستخدم `LocalAuth` باسم مستقل.
- الرسائل الواردة لا يتم تنزيل ملفاتها من واتساب.
- يمكن ربط كل جلسة بـ API مستقل.
