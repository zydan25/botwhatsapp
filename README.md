# WhatsApp Pro Multi Session

نظام متعدد الجلسات لإدارة WhatsApp Web عبر `whatsapp-web.js` مع لوحة تحكم عربية.

## التشغيل الآمن

انسخ `.env.example` إلى `.env` واضبط المتغيرات المطلوبة، ثم شغّل:

```bash
cp .env.example .env
npm install
npm start
```

المتغيرات الإلزامية هي `ADMIN_USERNAME` و`ADMIN_PASSWORD` و`SESSION_SECRET`.

افتح `http://127.0.0.1:3000` ثم سجّل الدخول. من لوحة التحكم يمكن إنشاء جلسات، تشغيلها، إيقافها، تسجيل الخروج منها، أو حذفها نهائيًا.

حذف الجلسة يحذف بيانات اعتماد WhatsApp المحلية وسجل الرسائل والأخطاء والتنبيهات الخاصة بها.

## الأمان

جميع صفحات الإدارة وواجهات `/api/*` محمية بتسجيل دخول عبر cookie `HttpOnly` و`SameSite=Strict`. اتصال Socket.IO يتطلب جلسة دخول صالحة.

رفع الوسائط محدود بالحجم والعدد، ويُحذف الملف المؤقت بعد محاولة الإرسال.

الخادم يستمع على `127.0.0.1` افتراضيًا.
